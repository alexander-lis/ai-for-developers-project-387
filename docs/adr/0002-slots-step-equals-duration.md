# Слоты нарезаются шагом продолжительности Типа встречи

Сетку Слотов можно было строить с общим шагом для всех Типов встреч (например, каждые 30 минут от начала Рабочих часов) и требовать, чтобы продолжительность Типа была кратна этому шагу. Вместо этого шаг стартов равен продолжительности выбранного Типа: для Типа на 30 минут Слоты начинаются в 09:00, 09:30, 10:00, для Типа на 45 минут в 09:00, 09:45, 10:30. Правило описывается одной фразой, не требует второго параметра Календаря, а продолжительность остаётся любым целым от 5 до 480 минут. Сетки разных Типов не совпадают, поэтому конфликты проверяются по пересечению интервалов Встреч, а не по совпадению Слотов.

## Consequences

- Длинные Типы дают «дырявую» сетку: Тип на 45 минут никогда не предложит начало в 10:00.
- Встреча одного Типа может занять лишь часть Слота другого Типа; такой Слот считается занятым целиком.
- Смена правила после появления Встреч оставит записи вне новой сетки: сервер должен проверять только пересечения, а не принадлежность старых Встреч сетке.

Решение принято в тикете карты [Правила времени: рабочие часы, часовой пояс, шаг стартов, окно записи](https://github.com/alexander-lis/ai-for-developers-project-386/issues/5).
